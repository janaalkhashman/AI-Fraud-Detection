 AI Fraud Detection

A machine learning project that detects potentially fraudulent credit card transactions using Python and Scikit-learn.

 Technologies Used
- Python
- Pandas
- Scikit-learn
- Logistic Regression

 Project Workflow
1. Load and explore the dataset.
2. Split the data into training and testing sets.
3. Scale the features using StandardScaler.
4. Train a Logistic Regression model.
5. Evaluate the model using Precision, Recall, and F1-score.
6. Save the trained model using Joblib.

 Model Performance
- Precision: 69%
- Recall: 85%
- F1-score: 76%

Note: Results are based on one train-test split and may vary with other data splits.*

 Dataset
The dataset is not included in this repository.

 Disclaimer
This project is for educational purposes and is not intended for use in real financial systems.
